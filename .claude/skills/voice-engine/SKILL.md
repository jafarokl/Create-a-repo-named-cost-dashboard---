# 05 · Voice Engine — *Emails, proposals and posts in your voice.*
Owner: **CMO**

## Setup (first run only)
1. Read `business-data/voice/voice-samples.md` (ideally 10+ real emails/posts written by the owner).
2. Build `business-data/voice/voice-guide.md`: tone (3 adjectives), sentence length, greeting/sign-off habits, words & phrases they use, words they never use, emoji/formatting habits, how formal per audience, 3 short "this is me / this is not me" examples.
3. Show the guide to the owner and refine it. If fewer than 3 samples exist, ask for more before writing.

## Every request
1. Read `voice-guide.md`, `company-profile.md` and the latest `outputs/cmo/*customer-read.md` (for customer language).
2. Clarify: format, audience, goal (the one action the reader should take), key facts, length.
3. Draft in the owner's voice. Structure by format:
   - **Email:** subject line options (3), short body, one clear ask.
   - **Proposal:** their problem in their words → outcome → scope → timeline → price/options → next step.
   - **Post:** hook line, one idea, a story or example, call to action; platform-appropriate length.
4. Self-check against the guide: would the owner say this out loud? Remove clichés ("I hope this email finds you well", "game-changer", "delve").
5. Offer one shorter alternative.

## Rules
Never invent facts, numbers, clients or testimonials — use `[PLACEHOLDER]`. Never send; drafts only. Save longer pieces to `outputs/cmo/drafts/<date>-<topic>.md`.
